## Selected work

**[learning_tree-ML-systems](https://github.com/maximecoia/learning_tree-ML-systems)** · Python, PyTorch

A public roadmap toward ML systems, from a GPT written by hand to measured
inference and a contribution to vLLM.

* [L1](https://github.com/maximecoia/learning_tree-ML-systems/tree/main/ms-00-prepa/l1-01-gpt-corpus):
  a character-level GPT trained on Jules Verne, attention written by hand.
